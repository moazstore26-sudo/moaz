# موطن — مستعمرة الوادي

مشروع النشر المجاني في mawten/. اللعبة ثلاثية الأبعاد مع حسابات وحفظ دائم ووقت خادمي حقيقي. Cloudflare Workers Free مع SQLite Durable Object.

الأسرار OWNER_PASSWORD_SALT وOWNER_PASSWORD_HASH تُضبط في Cloudflare فقط. الدفع غير مفعّل. اختصار مهمة واحدة600 ثانية مقابل20 ذهبًا؛ المالك مجانًا.

مستودع المشروع: https://github.com/moazstore26-sudo/moaz

يرتبط الفرع main بالنشر التلقائي على Cloudflare، من مجلد mawten باستخدام npx wrangler deploy. نقل إدارة المشروع لا يغيّر رابط اللعبة أو ربط قاعدة بيانات العالم الحالية.
